# Лабораторная работа №4
## Особенности использования данных различного типа

* **Автор:** Иванова Оксана
* **Группа:** бОТИ-261
---

### Описание
Программа на языке C, демонстрирующая работу с базовыми типами данных (`char`, `int`, `float`, `double`):

* **Задание 1:** ввод и вывод значений разных типов, целая и дробная часть числа, код символа, значение `1/i`.
* **Задание 2:** неявное и явное преобразование типов при делении.
* **Задание 3:** цифры трёхзначного числа (первая, последняя, сумма, число наоборот).
* **Домашнее задание:** условие показа направления «Налево», если только одно из чисел A и B чётное.
